 # AI-Based Data Security & User Behaviour Monitoring

A lightweight web security monitoring system that analyses user behaviour, detects suspicious data-access patterns, calculates risk scores, and helps administrators identify possible data theft, scraping, or abuse.

## Planned Features

- Member activity monitoring
- Profile view tracking
- Copy attempt monitoring
- Download monitoring
- Screen/session time tracking
- API request monitoring
- Central activity audit log
- Behaviour-based risk scoring
- Progressive user restrictions
- Rate limiting
- Admin security dashboard
- Suspicious-user activity timeline
- Security alerts
- AI-based anomaly detection

## Technology Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- Vanilla JavaScript

## Development Environment

Designed to remain lightweight and suitable for development on an Ubuntu system with 4 GB RAM.
